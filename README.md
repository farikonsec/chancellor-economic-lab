# Chancellor — UK Economic Lab

[Play the game](https://farikonsec.github.io/chancellor-economic-lab/).

Explore UK budgets, funding trade-offs, historical prices and economic scenarios in an interactive browser game. Entirely frontend; no backend or API keys. Sources and model limitations are explained in the app.

Run locally: `python3 -m http.server 8000`. Tests: `node check.cjs`.
